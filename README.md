# Catena plugin Revit

Instalador do add-in Catena para o Revit. O código-fonte não fica neste repositório.

## Instalar

1. Baixe o `.msi` na página de [Releases](https://github.com/dvalls/CatenaPluginRevit/releases).
2. Feche o Revit e execute o instalador. A DLL fica travada enquanto o Revit está aberto.
3. O Windows pode pedir permissão de administrador.
4. O instalador não é assinado. Na primeira vez, o SmartScreen pode pedir **Mais informações** e depois **Executar assim mesmo**.

As versões do Revit encontradas na máquina já vêm marcadas. Numa atualização, as versões marcadas na instalação anterior são mantidas.

## Install

Download the `.msi` from [Releases](https://github.com/dvalls/CatenaPluginRevit/releases), close Revit, and run it. Windows may ask for administrator permission. The package is not signed, so SmartScreen may ask for More info, then Run anyway, the first time.
